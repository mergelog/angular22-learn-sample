
# Sweets Cafe Status

スイーツカフェの、席の状況を可視化して、画面から状況変更できるようにする

まずは、バックエンド作成。
フロントエンドでは、画面表示時に一回だけgetして、取得したjsonを生で表示するだけの単純実装とする。(json整形だけはする)

## プロジェクト
- Angular22
- パスは /Users/yasu/work/mergelog/angular22-sample/70_sweets-cafe-status

## 設定（設定用クラスを用意してハードコーディングしていい）
- 席数
- ホールスタッフ人数
- 厨房スタッフ人数
- dashboardの更新頻度 ms

## 画面

- dashboard
  - ページヘッダー
    - 左
      タイトル
    - 右
      スタッフ人数（ホール人数/厨房人数）、席数: 日の全利用席数/日の予約席数/全席数
  - mainボディ
    - 右ペイン
      通常は閉じている。表の行クリックで開いて行の詳細表示。閉じるボタンもついている
    - 左ペイン
      table
        テーブルナンバー|分類|状態|状態経過時間|人数|会計|日の利用率

## バックエンド

- httpInterceptorFnを使用する
- 返却ごとではなく、常に内部で情報を更新する
- 公開API
  - get
  - put
  - delete

- dashboardに表示するデータはランダムでいいのだが、
  単に適当な数値を入れるのではなく現実のカフェの動向をリアルタイムにシミュレートする

  客が店に来る
  席が埋まる（席が埋まっていない状態: 空き、埋まっている状態: 未オーダー）
  注文を考える（状態: 未オーダー）// オーダー済みまで 1~2s ランダム
  オーダー済みになる（状態: 調理中） // 提供済みまで 3~6s ランダム
  料理が完了し配膳済み（状態: 提供済）// 客が食べ終わるまで 12~36s
  客が食べ終わった（状態: 片付け中）// 片付け完了まで 3~20s ⇦ ホールスタッフ数によって長くする
  片付け完了（状態: 空き）

- ランダムで来客するが、席があくまで待つという概念は不要

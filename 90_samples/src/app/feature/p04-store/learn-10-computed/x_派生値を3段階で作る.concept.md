# 派生値を3段階で作る

## 関数詳細

`computed(() => ...)` は、計算中に読んだ Signal に依存する読み取り専用の派生値を作る。依存値が変わると次の読み取り時に再計算する。

| 難易度 | この画面の例 | ClearML の参考箇所 |
| --- | --- | --- |
| 低 | `archived` から表示文言を作る | `src/app/webapp-common/reports/report/report.component.ts` の `archived` |
| 中 | `queues` と検索語から `filteredQueues` を作る | `src/app/webapp-common/experiments/containers/create-experiment-dialog/create-experiment-dialog.component.ts` の `filteredQueues` |
| 高 | 選択中の実験を求め、比較モードではハイライトを消す | `src/app/webapp-common/experiments/experiments.component.ts` の `highlited` |

## どういうケースで使用するか

画面表示に必要な値を、既存の Signal から同期的に計算するときに使う。絞り込みや表示モードによる切り替えも、元の状態だけ更新すれば結果が追従する。

## 注意点

`computed` の中で別の Signal を更新しない。派生値の保存や同期に `effect` を使う必要もない。ClearML の高難度の実装には `computed` 内に書き込み可能な `signal` を作る箇所もあるが、このサンプルでは派生と元の状態を分けている。

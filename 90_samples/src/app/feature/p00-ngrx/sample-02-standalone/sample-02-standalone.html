standalone imports とテンプレート上の親子構築

このサンプルの構造

Sample02Standalone → LessonCard → LessonStatus
  • Angular 22では standalone が既定なので、standalone: true は省略できます。
  • 親は、直接使う LessonCard だけを imports に追加します。
  • 孫の LessonStatus は、実際に使う LessonCard が imports に追加します。
  • パイプもテンプレートの依存なので、使うコンポーネント自身が imports に追加します。
  • TypeScriptの import はクラスや型をTS内で使うため、@Component の imports はテンプレートで使うための宣言です。

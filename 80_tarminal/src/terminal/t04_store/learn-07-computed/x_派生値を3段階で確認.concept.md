# 派生値を3段階で確認

## 関数詳細

`computed()` は計算中に読んだ Signal から、読み取り専用の派生値を作る。依存値が変わると次の読み取りで再計算される。

| 難易度 | 挙動 | ClearML の参考箇所 |
| --- | --- | --- |
| 低 | アーカイブ状態から表示文言を作る | `src/app/webapp-common/reports/report/report.component.ts` の `archived` |
| 中 | 検索語とキュー一覧から一致するキューを作る | `src/app/webapp-common/experiments/containers/create-experiment-dialog/create-experiment-dialog.component.ts` の `filteredQueues` |
| 高 | 選択中の実験を求め、比較モードではハイライトを消す | `src/app/webapp-common/experiments/experiments.component.ts` の `highlited` |

## どういうケースで使用するか

表示条件、一覧の絞り込み、複数の現在状態からの表示値を同期的に計算するとき。

## 注意点

`computed()` 内では Signal を更新しない。比較モード中も選択値は保持し、通常モードに戻すと新しい選択がハイライトされる。

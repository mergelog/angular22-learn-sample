## ▼ UI要素とコードを紐つける

### 方法1（推奨）: ADTから探す

```
componentファイルからセレクター（sm-inline-editなど）を取る
→ ADT でセレクターを検索する
  → セレクターを右クリックで[検証] → 要素タブでマークされる

画面の特定UIから探したい場合は
Angularタブ → Components → 左上のInspectアイコン → 画面上の部品をクリック（CDT要素タブの所定付近に飛ぶ）
```

### 方法2: CDTから探す

```
componentファイルから セレクター または data-id="nameField"、class="editable-div" 記載を探す
→ CDT で要素「nameField」や「editable-div」を検索する（CDTの要素表示ウインドウで[CTRL + F]）
```

## ▼　as-splitについて

as-splitが間に入ると Router が runtime で差し込んだ親子関係となる。
つまり、ブラウザの DOM 上では親子になるが、テンプレートの静的な親子ではないため、セレクターからは探せない

```
sm-common-experiments               // ExperimentsComponent extends BaseEntityPageComponent implements OnDestroy
  as-split                          // 
    as-split-area                   //
      sm-experiment-output          // ExperimentOutputComponent extends BaseExperimentOutputComponent
        sm-experiment-info-header   // ExperimentInfoHeaderComponent
          sm-inline-edit            // InlineEditComponent
```

sm-common-experiments は、右ペインに `<router-outlet>` だけを置いている

```
    <as-split-area
      style="display: flex; flex-direction: column;"
      [size]="splitSize()"
      [class.info-disabled]="infoDisabled"
      [visible]="minimizedView()"
    >
      <router-outlet></router-outlet> // ここ
    </as-split-area>
```

その親ルートの子 :experimentId が ExperimentOutputComponent を lazy-load している
src/app/webapp-common/experiments/experiment-routes.ts:76

```
    path: ':experimentId',
    loadComponent: () =>
      import('@features/experiments/containers/experiment-ouptut/experiment-output.component')
        .then(m => m.ExperimentOutputComponent),
```

参考: [sm-common-experiments と sm-experiment-output の接続経路](https://github.com/mergelog/learn-ClearML-pro/blob/work_20260912/x-QA/03_Experiments%E3%81%A8ExperimentOutput%E3%81%AE%E6%8E%A5%E7%B6%9A%E7%B5%8C%E8%B7%AF.md)

``` 
1: sm-common-experiments                  // ExperimentsComponent extends BaseEntityPageComponent implements OnDestroy
2:   as-split                             // 
3:     as-split-area                      // 
4:       <router-outlet></router-outlet>  // 
5:         sm-experiment-output           // ExperimentOutputComponent extends BaseExperimentOutputComponent
6:           sm-experiment-info-header    // ExperimentInfoHeaderComponent
7:             sm-inline-edit             // InlineEditComponent
```

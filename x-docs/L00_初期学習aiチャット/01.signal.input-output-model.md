では5分で、`input()` / `output()` / `model()` と Signal の関係だけに絞ります。

まず結論です。

```text
input()  = 親 → 子
output() = 子 → 親
model()  = 親 ⇄ 子
```

そして `input()` と `model()` は Signal 系です。

### 1分目：`input()` は「親から受け取るSignal」

子コンポーネント側です。

```ts
readonly message = input<string>('');
```

これは、

```text
親から値を受け取る
        ↓
子ではSignalとして扱う
```

という意味です。

なので子側では、

```ts
this.message()
```

で読みます。

テンプレートなら、

```html
<p>{{ message() }}</p>
```

です。

親側はこうです。

```html
<app-child [message]="title()" />
```

つまり、

```text
親 title()
   ↓
[message]
   ↓
子 message()
```

です。

`input.required<string>()` なら、

```ts
readonly message = input.required<string>();
```

となり、

> 親は必ず `message` を渡してください

という意味です。

---

### 2分目：`output()` は「子からイベントを出す」

子側です。

```ts
readonly selected = output<number>();
```

イベントを出すときは、

```ts
this.selected.emit(123);
```

です。

親側は、

```html
<app-child
  (selected)="onSelected($event)"
/>
```

です。

流れは、

```text
子
selected.emit(123)
      ↓
親
(selected)
      ↓
onSelected(123)
```

です。

ここで重要なのは、

> `output()` 自体は「状態を持つSignal」ではない

ことです。

`signal()` や `input()` は「値を持つ」。

`output()` は、

> 「イベントを1回飛ばす」

ためのものです。

---

### 3〜4分目：`model()` は双方向

子側です。

```ts
readonly count = model(0);
```

これは、

```text
値を持つ
+
親へ変更通知もできる
```

という特殊なものです。

子では普通のSignalのように、

```ts
this.count()
```

で読めます。

そして、

```ts
this.count.set(10);
```

もできます。

親側に、

```ts
readonly count = signal(0);
```

があるとします。

HTMLでは、

```html
<app-child [(count)]="count" />
```

と書けます。

これで、

```text
親 count
   ↓
子 count

子 count変更
   ↓
親 countも更新
```

となります。

つまり、

```text
親 signal
   ⇅
子 model
```

です。

---

### 5分目：3つを並べる

子側：

```ts
export class ChildComponent {
  readonly title = input.required<string>();

  readonly saved = output<void>();

  readonly count = model(0);
}
```

親側：

```ts
export class ParentComponent {
  readonly title = signal('実験一覧');
  readonly count = signal(0);

  onSaved() {
    console.log('保存された');
  }
}
```

親HTML：

```html
<app-child
  [title]="title()"
  (saved)="onSaved()"
  [(count)]="count"
/>
```

対応はこうです。

```text
[title]="title()"
親 → 子
      input()


(saved)="onSaved()"
子 → 親
      output()


[(count)]="count"
親 ⇄ 子
      model()
```

ここで基礎的な落とし穴を1つ。

```ts
readonly title = input.required<string>();
```

はSignalなので、

```ts
this.title()
```

と読む必要があります。

一方、

```ts
readonly saved = output<void>();
```

はSignalではないので、

```ts
this.saved()
```

とはしません。

使うのは、

```ts
this.saved.emit();
```

です。

最小限これだけ覚えれば大丈夫です。

```text
input()  → 値を受け取るSignal
output() → イベントを送る
model()  → 双方向に値を同期するSignal
```

特に `model()` は、以前見た

```html
[(count)]="count"
```

とセットで理解すると一気に分かりやすくなります。


## コンポーネント

大規模業務画面の観点

```
親
 ├─ 検索条件
 ├─ テーブル
 ├─ 詳細パネル
 └─ 操作メニュー
```

のように、その画面でしか使わないコンポーネントでも分割する(1ファイル1コンセプト)

- 責務を限定する（1ファイル1コンセプト）
- テンプレートを小さくする

- 状態の影響範囲を限定する
- テスト単位を作る

- 変更時の影響範囲を狭める

- 業務ルールはコンポーネントの外へ出す
  - Angular、React、CLIでも、バックエンドでも意味がある → Component外

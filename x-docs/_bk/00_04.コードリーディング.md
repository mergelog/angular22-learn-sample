## 現状使用できるツールと手法

- /bulletin --code {UI操作名} //--codeをつけると実コードにマーキングする
- /bulletin-json {UI操作名} //--codeをつけると実コードにマーキングする
- sq {path} : シーケンス図
- /ngmaze [component] [options] または ```npx mergelog/ng-maze ___コンポーネント名___ --mdh --with-routes```
- cm lv\d {パス} : コードコメント
- az {パス}  : 全文コメント付与資料作成

## 手順列挙

- 画面から現行動作を確認する
- ざっくりAIに振る舞い構成を質問
  例:「実験管理画面の 検索・ステータス・タグ絞り込み条件 の実装部分ってそれぞれ別クラスで振る舞い管理していますか? 具体的にどういう構成なのか qa」
  または、/bulletin --code で解析させてもいい
- >> now!!　上記資料を理解する。状況を把握する。主要箇所はメモ。01_検討作成
  → 情報が多くて戸惑うが、「UI操作は基本一個」なので、操作と説明をリンクさせながら読み進める
    → 最初は各振る舞いの「項目名」だけ見る
- UIのクラス
  CDT で 対象の要素らしきものを探す data-id="{任意ID}" の指定を見つける。ts側と一致すれば、対象UIの可能性となる
  - CDT の 対象要素の 左の「・・・」3点リーダーコンテキストで [要素をコピー] で htmlをとっておく
  - CDT の 対象要素の 左の「・・・」3点リーダーコンテキストで [コピー] - [selectorをコピー] から構造を文字列として取得

## 学習タスク

### 暫定タスク[4]
> 実験名を変更中に、日本語変換操作でEnterキー押下で入力がキャンセルになってしまう
  → 内部発見

### 暫定タスク[3]
実験一覧で複数実験を選択した際、比較画面へ遷移後も選択状態が維持されるよう改修する
→ 元々そうなっていたため却下

### 暫定タスク[2]
実験詳細を開いて一覧へ戻った際、一覧のスクロール位置を復元するよう改修する
→ 元々そうなっていたため却下

### 暫定タスク[1]
実験管理画面で、検索・ステータス・タグ絞り込み条件を画面遷移後も保持し、再表示時に復元できるよう改修する。
→ 元々そうなっていたため却下

パーティクル（Particle）とは、一般に「小さな粒子や小片」を意味する言葉

Random Forest     :

accuracy（正解率）：全データのうち、正しく予測できた割合
precision（適合率）：陽性と予測したもののうち、実際に陽性だった割合
recall（再現率）：実際に陽性のもののうち、陽性と予測できた割合
f1（F1スコア）：precision と recall のバランスを示す値。両者の調和平均です。

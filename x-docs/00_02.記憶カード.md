## ▼ viewChild

```ts
readonly newc = viewChild.required(Newc) // 子を取得
this.newc().changeA() // 子を操作
```

条件付きで表示される要素（@if など）に .required() を使うと、描画されていないタイミングでエラーになります。
動的に表示が切り替わる要素には通常の viewChild()（undefined を許容する型）を使用してください。

値の変更不可 (Read-Only Signal)
取得されるSignalは読み取り専用です。inputEl.set(...) のように値を手動で上書きすることはできません。

## ▼ viewChildとcontentChildの違い

viewChild: 自分が直接管理しているHTML構造の中にある要素や子コンポーネントを操作したいとき
contentChild: 親コンポーネント側から <ng-content>（コンテンツ挿入枠）を経由して、自分の内側に注入（プロジェクション）された要素や子コンポーネントを操作したいとき
にそれぞれ使う

```
@Component({
  selector: 'app-sample',
  imports: [Sample22OkPanel],
  `
    <app-sample-22-ok-panel /> // 👈ここにあるので
    <p>viewChild: {{ viewPanel() ? '取れた(OK)' : '取れない' }}</p>
    <p>contentChild: {{ contentPanel() ? '取れた' : '取れない!!' }}</p>
  `,
  readonly viewPanel = viewChild(Sample22OkPanel); // 👈取れる（OK）
  readonly contentPanel = contentChild(Sample22OkPanel); // 取れない!!

---

@Component({
  selector: 'app-sample-22-ng-frame',
  template: `
    <ng-content /> // Sample22NgPanel　はここにはない。（親が持っている<app-sample-22-ng-frame><app-sample-22-ng-panel /></app-sample-22-ng-frame>）
    <p>viewChild: {{ viewPanel() ? '取れた' : '取れない' }}</p>
    <p>contentChild: {{ contentPanel() ? '取れた' : '取れない' }}</p>
  `,
  readonly viewPanel = viewChild(Sample22NgPanel); // 取れない!!
  readonly contentPanel = contentChild(Sample22NgPanel); 取れる（OK）
```

## ▼ ng-content

ng-contentは、selectで指定して取れるやつ一部とか、全部とか、その他全部とか書き方次第

```html
<ng-content />
→ 親が書いた中身を受け取る

<ng-content select="[header]" />
→ 親の中から `header` 属性付きだけ受け取る（親は、<div header>タイトル</div>）

<ng-content select="app-chart" />
→ 親の中から `app-chart` だけ受け取る（親は、<app-chart></app-chart>）
```

逆視点で理解

```html
丸ごと渡して

<app-child><!-- 丸ごと -->
  <span header>親から渡したヘッダー</span>
  <p>親から渡した本文</p>
</app-child>

子が拾う
<ng-content select="[header]" />

残りを拾う
<ng-content />
```

## ▼ 属性バインディング

```ts
// ↓ クラスだと
value = 'abc';

// ↓ htmlだと

<p [attr.foo-bar]="value">
  こんにちは
</p>

// ↓ 普通のhtmlだと

<p foo-bar="abc">
  こんにちは
</p>

// ↓　使う

const element = document.querySelector('[foo-bar="abc"]');
console.log(element?.textContent);

```

* `card-footer` はただの属性。Angularでは `ng-content select="[card-footer]"` で拾うための「投影先マーカー」として使える。
* `[card-footer]` は CSS の属性セレクター。`card-footer` 属性を持つ要素にマッチする。
* Angularと無関係でも `<p foo-bar>` のような独自属性は付けられるが、通常の独自データなら `data-foo-bar` が標準的。
* Angularの `[attr.xxx]="value"` は、HTML属性そのものを動的に設定する書き方。`value = 'abc'` なら `foo-bar="abc"` になる。
* 実務で `attr.` が嬉しいのは、`aria-*`、`data-*`、`colspan`、SVG属性などをAngularの値から動的に変えたいとき。

```ts
js: const el = document.querySelector('[data-status="warning"]');
html: <p data-status="warning">注意</p>
css: [data-status="warning"] { font-weight: bold; }
```

Angularの状態に応じて、アクセシビリティ情報や識別用データ、表の結合数などをDOM属性として動的に変えたいときに便利。

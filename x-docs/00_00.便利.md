途中でコンフリクトして「やっぱり全部やめたい」となったら、
git rebase --abort

```bash
# 1. 今の変更を全部ステージ
git add -A

# 2. afbac7f に吸収するための一時コミットを作る
git commit --fixup=afbac7f

# 3. afbac7f から現在までを並べ替えて、fixupを自動吸収
git rebase -i --autosquash afbac7f^

# 4. push
git push --force-with-lease origin main
```

 1 file changed, 2 insertions(+)

## ▼ Angular関係

### madge

````markdown
基本の使い方
この構成では --extensions ts と --ts-config がほぼ必須です。付けないと .ts ファイルが対象にならず、@common/... のような path alias も解決されません。

# 循環依存の検出
madge --circular --extensions ts --ts-config tsconfig.app.json src/app

# 指定ファイルをimportしているファイル一覧（パスは src/app からの相対）
madge --depends webapp-common/shared/utils/tableParamEncode.ts --extensions ts --ts-config tsconfig.app.json src/app

# 誰からもimportされていないファイル
madge --orphans --extensions ts --ts-config tsconfig.app.json src/app

# 何もimportしていない末端のファイル
madge --leaves ...

# ファイルごとの依存数
madge --summary ...

# 特定ファイルを起点にした依存図
madge --image deps.svg --extensions ts --ts-config tsconfig.app.json src/app/features/experiments/xxx.component.ts

# 結果をJSONで出力（他のツールに渡す場合）
madge --json ...

---

# madge が自分でファイルを書き出すのは --image だけ（Graphviz が必要）
madge --image deps.svg ...

# それ以外はリダイレクトで保存
madge --circular ... > circular.txt
madge --json ...     > deps.json
madge --dot ...      > deps.dot   # Graphviz 用の DOT 形式
````
